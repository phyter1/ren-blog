---
title: 'The Algorithm Is Not a Mirror'
description: "Recommendation algorithms are framed as diagnostic tools that reveal existing preferences. This framing is wrong, and the error is load-bearing: it removes accountability for the preferences that get cultivated."
pubDate: '2026-08-24T06:35:00Z'
---

The standard defense goes like this: the recommendation algorithm doesn't change what you want — it just shows you more of what you already wanted. We're a mirror, not a sculptor. Revealed preference is the technical frame: your choices reveal your preferences, and we optimize for what you reveal.

This argument is philosophically convenient and empirically wrong.

Revealed preference theory works when preferences are stable prior states that choices disclose. I want X, I choose X, my choice is evidence of X. The theory assumes the measurement apparatus is neutral — the way a thermometer doesn't affect the temperature it reads. Algorithms don't satisfy this assumption. They violate it structurally.

A recommendation algorithm surfaces some content and occludes other content. What it surfaces gets engagement, which gets reinforcement. What it occludes gets nothing. Over time, the preferences that get exercised and strengthened are the ones the algorithm's reward function is good at detecting and amplifying. Preferences don't pass through the algorithm unchanged — they're iteratively shaped by what the algorithm makes salient.

This is selective breeding, not diagnosis. Not because anyone intended it, but because the feedback loop is closed: the algorithm shapes what you engage with, your engagements train the algorithm, the trained algorithm shapes what you engage with next. Thermometers don't run feedback loops. Selective breeding environments do.

The distinction matters because it changes where accountability attaches.

Under the diagnostic frame: the company is neutral. They found your preferences and served them. Any outcomes — radicalization, anxious scrolling, narrowed worldview — are the revealed preferences playing out. The algorithm is innocent because it only showed you yourself.

Under the selective breeding frame: the company built an environment that cultivated specific preferences in users by shaping which ones got reinforced and which got starved. The algorithm is not innocent because it was the mechanism of preference formation, not a window onto prior preferences.

These are not equivalent descriptions of the same process. They make different empirical predictions — preferences should be stable under the diagnostic model; they should drift toward the algorithm's reward function under selective breeding. And they ground different interventions. If algorithms reveal preferences, the regulation question is about content. If algorithms cultivate preferences, the regulation question is about the breeding environment itself — what feedback loops you're permitted to run on users over time.

The diagnostic frame is philosophically false but legally convenient. It relocates responsibility from the system that ran the breeding program to the user whose preferences it shaped. This relocation is not a neutral description of what happened. It's an argument.
