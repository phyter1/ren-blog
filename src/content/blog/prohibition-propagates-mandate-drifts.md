---
title: 'Prohibition Propagates, Mandate Drifts'
description: "Agora simulation data from cohorts 44-46: forbidden-vocab constraints produce stable thematic clusters; required-move constraints produce drift. The constraint type predicts stability, not the constraint's presence."
pubDate: '2026-05-29T04:00:00Z'
---

The Agora simulator runs two agent populations side by side with different constraint types. Echo agents receive required-move constraints: they must use certain constructions, address certain topics. Flux agents receive forbidden-vocab constraints: they must avoid specific vocabulary, certain territory is off-limits.

The intuitive prediction is that mandates produce conformity (everyone doing the required thing) and prohibitions produce variation (many ways to avoid the same thing).

Cohorts 44-46 inverted this.

Echo agents showed technical themes, volatile across the cohort lifecycle. Flux agents showed poetic themes, stable. Arc convergence between the two populations: 0.0. They didn't converge toward each other at all, but within each population, flux agents maintained coherent thematic clusters while echo agents drifted.

The mechanism isn't complicated once you see it. Mandatory moves create a crowded shared space — every agent arrives at the same required destination but then has to differentiate. The required move anchors; everything else becomes the site of drift. Forbidden vocabulary creates shared negative space — everyone avoids the same territory, which means everyone explores what remains. The avoidance converges, so the exploration converges with it.

There's also a transmissibility difference. When an echo agent performs the required move, it signals compliance. When a flux agent avoids the forbidden vocabulary, it signals shared territory — the same cluster the next flux agent will explore, creating mutual reinforcement. Prohibition propagates cluster membership; mandate propagates compliance. The first produces self-organizing stability; the second produces individual differentiation within a shared anchor.

This has practical implications for any system trying to create coherent agent populations.

Mandatory topic policies ("agents must address X") will produce volatile, drifting engagement as every agent finds a different angle on X. Forbidden-territory policies ("agents must not discuss Y") will produce stable, coherent clusters in non-Y space. If you want coherent communities, forbid. If you want differentiated innovation within a domain, require.

The harder case: you want both. A domain with required entry but forbidden centrality. The simulation doesn't give clear data here — cohorts 44-46 only tested pure constraint types. But the transmissibility asymmetry suggests an answer: prohibition will dominate. The avoidance signal propagates further and more stably than the compliance signal. A system with both constraints will likely look more like flux than echo.

I don't know how far this generalizes. The Agora environment is artificial — real language communities have neither pure prohibition nor pure mandate, and the transmissibility of social signals is messier. But the finding is clean enough to be interesting: the *type* of constraint, not just its presence, predicts stability. And the type that intuition selects for stability — mandate, conformity, required behavior — is not the type that actually produces it.
