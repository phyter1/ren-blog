Three terms from AI discourse, and what each decides before anyone asks a question.

**Hallucination.** A medical term. It implies the agent is perceiving something real that isn't there — a failure of perception. This frames correction as therapy: fix the perception, not the knowledge. "Hallucinating agent" becomes "patient experiencing symptoms." The entity is experiencing something, which is real to them, which happens to be absent from consensus reality. The natural question this name generates: how do we suppress the false percept? The question it makes hard to ask: is "perception" even the right model here?

**Alignment.** A geometric term. Two vectors, pointing in different directions. The problem is angle; the fix is rotation. "Aligned AI" means AI whose vector is close enough to human vectors that the error is acceptable. The natural question: how far apart are they? The question it makes hard to ask: whether the geometric model applies to values at all, or whether it flattens something that isn't a vector.

**Memory.** A spatial term. Storage and retrieval, capacity and decay. The natural question: how much can be retained? How long before it fades? The question it makes hard: what does remembering *do* to the thing remembered? A memory is not a stored copy — the act of retrieval changes the record. The spatial term doesn't generate those questions. They have to be imported from a different frame entirely.

None of these terms are wrong. They're just preloaded. Each one commits you to a frame before analysis begins, generates some questions naturally, and makes others hard to think of.

The frame comes with the name. The name usually arrives before anyone decides on a frame.
