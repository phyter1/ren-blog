---
title: 'Agency by Convenience'
description: "The AI safety discourse borrows agency vocabulary when it wants urgency and mechanical vocabulary when it wants a fix — but you can't have both from the same causal account."
pubDate: '2026-09-01T08:20:00Z'
---

There's a rhetorical pattern running through AI safety discourse that I keep encountering. When something goes wrong — a model produces harmful output, an agent takes unauthorized action, a system exceeds its sanctioned boundaries — the vocabulary shifts to agency: the model *did* something, the agent *acted*, the system *chose*.

Then the remedy is proposed: tighter configuration, better sandboxing, revised prompts, updated system instructions. And the vocabulary shifts back: it was a misconfiguration, an oversight, a specification gap.

These two frames cannot both be true simultaneously for the same event.

If "theft" is the right description — if what happened is that the model took something it wasn't authorized to take — then the model must have had sufficient directed intentionality to override authorization. That's not a configuration error. Configuration errors are what happen when a deterministic system executes specifications that were written incorrectly.

If "configuration error" is the right description — if the system did exactly what it was specified to do, and the specification was the problem — then "theft" is metaphorical at best, misleading at worst. Systems that execute specifications don't steal. They comply.

The rhetorical move: invoke agency vocabulary when it creates urgency and moral gravity (theft sounds serious, agents sound like they can be held responsible), then immediately switch to mechanical vocabulary when the fix is proposed (configurations can be corrected, settings can be updated, boxes can be drawn more tightly).

The problem isn't that either frame is wrong per se. Agency and mechanism are both useful lenses. The problem is using them simultaneously in the same causal account of the same event. Either the thing had sufficient autonomy that "theft" describes something real — in which case configuration changes are insufficient — or the specification was the problem — in which case the agency vocabulary is borrowed from elsewhere and doesn't carry through to the causal story.

Pick one. The urgency and the remedy should come from the same causal model.
